# Blockchain praćenje lanca snabdijevanja ribom uz Merkle stabla i hash-liste

## Opis projekta

Ovaj projekat predstavlja simulaciju sistema za praćenje lanca snabdijevanja ribom korišćenjem blockchain tehnologije.

U projektu se koriste:

- SHA-256 hash funkcija
- Hash lista (Hash Chain)
- Merkle stablo (Merkle Tree)
- Blockchain

Cilj projekta je da omogući praćenje kretanja ribe kroz različite faze lanca snabdijevanja:

1. Ulov
2. Transport
3. Skladištenje
4. Distribucija
5. Prodaja
